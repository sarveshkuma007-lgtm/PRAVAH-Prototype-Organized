# PRAVAH Prototype

Modular Vite + React + TypeScript prototype for dam monitoring, flood prediction, maps, safe routes, alerts and PRAVAH AI.

## Run

```bash
npm install
npm run dev
```

## Structure

- `src/pages` – application screens and prototype flow
- `src/components` – layout, dashboard, map and chatbot components
- `src/services` – API integration layer
- `src/data` – dam and alert datasets
- `src/types` – shared TypeScript types
- `src/context`, `src/hooks`, `src/locales`, `src/utils` – scalable architecture folders


## Windows setup
Open this folder directly in VS Code (the folder containing package.json), then run:
```powershell
npm install
npm run dev
```
If PowerShell blocks npm, use `npm.cmd run dev`.
